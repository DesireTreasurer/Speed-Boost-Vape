# Common problems

<details><summary>You opened the archive rather than a folder</summary>

Unpacking has to come first. A double-click only works after that.
</details>

<details><summary>Window opens behind other windows</summary>

Alt+Tab brings it to the front. On the next start the window remembers where it was closed.
</details>

<details><summary>Zip tool reports extraction failed</summary>

Try a different unpacker. The file is a plain zip, so built-in Windows Explorer or 7-Zip both handle it.
</details>

<details><summary>A protection rule stopped the write</summary>

Controlled Folder Access is what blocked the write. Allow `setup` there, or extract to a folder Windows already trusts.
</details>

<details><summary>A single file was copied and the rest stayed</summary>

Move `setup` back so the other files are with it again. Extracting the archive once more does the same job.
</details>

<details><summary>Windows left a block on the saved file</summary>

Finding Unblock under Properties and ticking it clears the block. Start `setup` once that is done.
</details>
